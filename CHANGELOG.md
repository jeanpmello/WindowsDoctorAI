# Changelog

Este arquivo registra mudanças relevantes do Windows Doctor AI. Enquanto o produto estiver em planejamento, entradas descrevem a evolução dos documentos; elas não implicam que funcionalidades de software tenham sido implementadas.

## [Unreleased]

- Criada a estrutura inicial de documentação do produto: visão geral, requisitos, arquitetura proposta, roadmap, segurança, banco de dados e orientações de contribuição.
- Registrados os limites iniciais para diagnóstico, consentimento em reparos, privacidade e uso opcional de IA.
- Documentadas as tecnologias planejadas e a necessidade de confirmar o alvo .NET antes da implementação, devido à data de fim de suporte do .NET 9.
